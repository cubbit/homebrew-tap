# Cubbit Tap

## DittoFS

A modular virtual filesystem with pluggable storage backends. [Repository](https://github.com/cubbit/dittofs)

```bash
brew install --cask cubbit/tap/dfs      # Server daemon
brew install --cask cubbit/tap/dfsctl   # Client CLI
```
