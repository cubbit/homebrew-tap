# Cubbit Tap

## How do I install these formulae?
`brew install --cask cubbit/tap/cubbit`

Or `brew tap cubbit/tap` and then `brew install --cask cubbit`.

## Documentation
`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).

## DittoFS

A modular virtual filesystem with pluggable storage backends. [Repository](https://github.com/cubbit/dittofs)

```bash
brew install --cask cubbit/tap/dfs      # Server daemon
brew install --cask cubbit/tap/dfsctl   # Client CLI
brew install --cask cubbit/tap/dfs-pro  # Pro dashboard
```
